# Building Replicator for the All Things Agentic Hackathon

> I created this article for the purpose of entering Google's All Things Agentic Hackathon.

Most scientific AI demos stop when code is generated. Replicator starts there. This article explains
how IDs-only events, Firestore transactions, restricted Cloud Run Jobs, evidence contracts, failure
memory, Gemini multimodal verification, and Google IAM signatures turn an LLM workflow into an
inspectable autonomous system.
